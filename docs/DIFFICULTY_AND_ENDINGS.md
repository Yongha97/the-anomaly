# 난이도·게임 목적·엔딩

> 상태: 방향 제안. 난이도 명칭과 정확한 배율은 미정

## 1. 게임 목적

플레이어의 목표는 단순히 오래 생존하는 것이 아니라 자신만의 공동체가 어떤 결말에 도달할지 결정하는 것이다.

- 생산 중심 공동체
- 강한 군사 세력
- 외부 세력과 공존하는 연합
- 의학과 기술 중심의 재건 세력
- 소수 정예 생존 집단

플레이 방식, 세력 관계, 시설, 생존자 수, 사망 기록과 주요 선택을 조합해 여러 엔딩을 제공한다.

## 2. 엔딩 구조

### 엔딩 후보

- 재건 엔딩: 거점과 생산 시설을 완성해 정착 도시를 건설
- 연합 엔딩: 다수 세력과 동맹을 맺어 지역 연합 형성
- 정복 엔딩: 경쟁 세력을 제압하고 지역 통제
- 탈출 엔딩: 차량과 보급품을 완성해 안전지대로 이동
- 연구 엔딩: 의료·제작 연구와 서적을 모아 생존 기술 확립
- 붕괴 엔딩: 사기, 식량 또는 관계 붕괴로 공동체 해산
- 고립 엔딩: 외부 관계를 끊고 소수 생존에 성공

각 엔딩은 조건을 처음부터 전부 공개하지 않고 진행 중 단서와 목표를 제공한다.

## 3. 다회차 요소

- 달성한 엔딩을 엔딩 도감에 기록한다.
- 엔딩별로 새로운 시작 배경, 성격, 외형 파츠 또는 규율을 해금한다.
- 해금 요소는 편의와 선택지를 늘리되 다음 회차의 난이도를 무력화하지 않는다.
- 이전 회차의 대표 구성원과 주요 사건을 연대기로 보존한다.

## 4. 난이도 후보

난이도는 아직 미정이며 다음 변수를 조정하는 방식으로 설계한다.

- 시작 자원
- 식량 소비
- 야간 위협 증가 속도
- 부상, 의료 사고와 사망 확률
- 관계 악화 속도
- 시설 건설 및 제작 시간
- 원정 보상
- 자동 저장과 되돌리기 허용 범위

초기 후보:

- 이야기: 낮은 사망 위험, 풍부한 자원, 관계 회복 보너스
- 생존: 기본 밸런스
- 종말: 부족한 자원, 빠른 위협 증가, 의료 사고와 사망 위험 증가
- 사용자 설정: 세부 변수를 직접 선택

영구 저장 삭제나 되돌릴 수 없는 철인 모드는 별도 선택 사항으로 둔다.
