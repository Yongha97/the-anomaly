# BM·광고 정책

> 상태: 앱 전환 이후 검토. 현재 웹 프로토타입에는 광고와 결제가 없다.

## 1. 기본 원칙

- 핵심 생존 루프와 모든 엔딩은 무료 플레이로 달성할 수 있어야 한다.
- 광고 시청은 강제가 아닌 선택형 보상 광고로만 제공한다.
- 사망 회피, 확정 영입, 능력치 직접 판매처럼 밸런스를 무너뜨리는 상품은 판매하지 않는다.
- 결제 여부가 난이도와 원정 확률을 바꾸지 않는다.

## 2. 시간 기반 작업

건물 건설, 시설 업그레이드와 고급 제작에는 게임 내 작업 시간을 부여한다.

- 담당 구성원의 건축 또는 제작 능력에 따라 소요 시간이 감소한다.
- 게임을 진행하면 작업 시간이 자연스럽게 줄어든다.
- 작업 중인 구성원은 다른 임무에 참여할 수 없다.
- 짧은 기본 작업에는 광고를 노출하지 않는다.

## 3. 선택형 보상 광고

광고를 시청하면 현재 작업 하나의 남은 시간을 일정량 또는 일정 비율 줄인다.

- 예시: 남은 시간 20% 감소 또는 게임 내 1일 작업량 추가
- 하루 이용 횟수에 상한을 둔다.
- 광고를 보지 않아도 정상적인 진행 속도로 완료할 수 있다.
- 원정 결과 재추첨, 사망 취소와 관계 판정 변경에는 사용할 수 없다.

정확한 감소량은 전체 플레이 시간과 작업 대기 시간을 측정한 뒤 확정한다.

## 4. 패스권

광고를 원하지 않는 플레이어를 위한 선택 상품이다.

- 보상 광고를 제거한다.
- 광고 보상과 동등한 일일 시간 단축권을 제공한다.
- 전용 능력치, 확률 보정 또는 엔딩은 제공하지 않는다.
- 영구 광고 제거 상품과 기간제 패스 중 어떤 형태를 사용할지는 미정이다.

## 5. 무료 이용

- 결제나 광고 시청 없이도 모든 작업은 게임 진행으로 완료된다.
- 일일 무료 시간 단축권을 소량 제공하는 방안을 검토한다.
- 장시간 접속하지 않아도 복귀 시 일부 작업 진행도를 반영한다.

## 6. 검토 사항

- 웹 버전에서는 광고 SDK를 붙이지 않는다.
- Capacitor 앱 전환 이후 플랫폼 정책과 연령 등급을 확인한다.
- 임신, 절단, 사망 등 민감한 사건 직후에는 광고 제안을 표시하지 않는다.
- 아동 대상 광고, 확률형 상품과 과도한 결제 유도는 사용하지 않는다.
