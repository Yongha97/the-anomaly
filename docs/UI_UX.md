# UI·UX 확장 기획

> 상태: 피로·무드·정신력·관계·상황별 가이드 1차 구현 완료

## 1. 가이드 시스템

### 첫 플레이 가이드

- 첫 시작 시 핵심 기능을 단계별로 한 번씩 안내한다.
- 순서: 구성원 확인 → 임무 배치 → 피로 확인 → 원정 편성 → 하루 보내기 → 보고서 확인
- 화면 전체를 막지 않고 대상 UI만 강조하는 코치 마크 방식을 사용한다.
- `건너뛰기`, `다시 보지 않기`, `도움말에서 다시 보기`를 제공한다.

### 상황별 가이드

- 식량이 3일치 미만이면 농사 배치를 안내한다.
- 피로가 위험 단계인 구성원이 있으면 휴식을 안내한다.
- 무드가 최하 단계에 진입하면 번아웃 조건과 대응 방법을 안내한다.
- 부상자가 생기면 의무실과 의료 담당 배치를 안내한다.
- 관계 악화가 무드에 영향을 주기 시작하면 관계 화면을 안내한다.

## 2. 구성원 상태 UI

구성원 카드와 상세 화면에 다음 상태를 표시한다.

- 체력: 녹색 막대
- 피로: 노란색 → 주황색 → 빨간색 단계 막대
- 무드: 표정 아이콘과 단계명
- 정신력: 숫자와 방패형 아이콘
- 부상 및 재활 남은 기간
- 번아웃 위험도
- 현재 관계 버프·디버프

### 피로 단계

- 0~24: 여유
- 25~49: 보통
- 50~74: 피곤
- 75~89: 탈진 직전
- 90~100: 탈진

피로가 75 이상이면 능력 효율 저하를 명확히 표시하고, 90 이상이면 원정 배치에 경고를 표시한다.

### 정신력 UI

- 정신력 수치 옆에 현재 무드 손실 완화율을 표시한다.
- 최근 무드 변화 원인을 최대 5개까지 표시한다.
- 예: `친한 구성원과 대화 +2`, `동료 사망 -12`, `과로 -4`

## 3. 관계 UI

### 관계 화면

- 구성원 상세 화면에 `관계` 탭을 추가한다.
- 나와 다른 구성원 사이의 관계 수치와 관계 단계를 표시한다.
- 관계 단계: 원수 / 불편 / 중립 / 친함 / 절친 / 연인 / 배우자
- 양방향 관계를 각각 관리한다. 한쪽만 친하다고 느끼는 비대칭 관계가 가능하다.

### 최근 대화

- 최근 대화와 사건을 최대 10개까지 기록한다.
- 긍정적인 대화는 당일 무드를 소폭 올린다.
- 부정적인 대화는 당일 무드를 소폭 내린다.
- 같은 대화 유형의 무드 효과는 하루 상한을 둬 반복 악용을 막는다.

## 4. 화면 구조

기존 하단 4개 탭은 유지한다.

- 현장: 거점 상황, 작업 인원, 야간 위협
- 생존자: 상태, 능력, 관계, 부상, 장비
- 원정: 편성, 규율, 영입 방침, 결과
- 관리: 시설, 제작, 세력 관계, 일지

구성원 상세 화면의 내부 탭은 `상태 / 능력 / 관계 / 장비 / 기록`으로 구성한다.

## 5. 접근성과 모바일 대응

- 색상만으로 상태를 구분하지 않고 아이콘과 단계명을 함께 사용한다.
- 주요 터치 영역은 최소 44px을 유지한다.
- 위험한 선택에는 확인 단계를 추가한다.
- 긴 보고서는 접기·펼치기와 원인별 필터를 제공한다.
